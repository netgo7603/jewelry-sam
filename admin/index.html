🔍 네이버 서치어드바이저 & 구글 서치콘솔 등록 관리

주얼리 샘의 블로그 포스트와 웹사이트가 네이버 검색 및 구글 검색 결과(AI Overview 포함)에 빠르게 노출될 수 있도록 자동 생성 도구와 제출 가이드를 제공합니다.

📄 1. Sitemap.xml & RSS 피드 자동 다운로드
현재 작성된 블로그 포스트를 반영한 최신 `sitemap.xml`과 `rss.xml` 파일을 즉시 다운로드하여 서버 또는 GitHub 저장소에 업데이트할 수 있습니다.
🟢 2. 네이버 서치어드바이저 (Naver Search Advisor) 등록 방법
1. 네이버 서치어드바이저 로그인 후 [웹마스터 도구] ➡️ 사이트 등록에서 https://jewelrysam.kr (또는 도메인) 추가
2. 네이버에서 발급하는 소유확인 메타태그 (<meta name="naver-site-verification" content="...">) 발급받기
3. 웹마스터 도구 ➡️ [요청] ➡️ [사이트맵 제출]에서 sitemap.xml 제출하기
4. [요청] ➡️ [RSS 제출]에서 rss.xml 제출하기
🔵 3. 구글 서치콘솔 (Google Search Console) 등록 방법
1. 구글 서치콘솔 접속 후 사이트 URL 주소 추가
2. [Sitemaps] 메뉴 클릭 ➡️ sitemap.xml 입력 후 [제출]
3. 신규 블로그 글 작성 시 [URL 검사] 메뉴에서 해당 글 URL을 넣고 [색인 생성 요청]을 누르면 Google AI Overview에 빠르게 노출됩니다.
